결혼 준비 앱 실행 폴더

[쓰는 법]
1. 이 폴더를 원하는 곳(예: 바탕화면)에 두고 start.bat 을 두 번 눌러요.
2. GitHub에서 최종본을 받아 app\index.html 로 저장한 뒤 기본 브라우저로 열어요.
   - PR #5가 검토 중이면 그 작업본(claude/eager-pasteur-qydyfn)을 받고, 반영된 뒤에는 main을 받아요.
   - 실행할 때마다 새로 받아요. 인터넷이 안 되면 전에 받아 둔 app\index.html 을 열어요.
   - 바로 전 버전은 app\index.prev.html, 받은 곳과 시각은 app\version.txt 에 남아요.

[처음 실행할 때]
- 'Windows의 PC 보호' 창이 뜨면 '추가 정보' → '실행'을 누르세요. 인터넷에서 받은 실행 파일이라 뜨는 안내예요.
- 검은 창이 잠깐 떴다가 브라우저가 열리면 정상이에요. 받지 못했을 때만 창이 멈춰 있어요.

[입력한 내용은 어디에 저장되나요]
- 이 컴퓨터의 브라우저에만 저장돼요. start.bat으로 새 버전을 받아도 같은 자리의 파일을 바꾸기만 해서 입력값은 그대로예요.
- GitHub Pages 주소, claude.ai 앱, 다른 브라우저와는 데이터가 따로예요.
- 폴더를 옮기거나 다른 브라우저로 열면 입력값이 안 보일 수 있어요. 한곳에 두고 같은 브라우저로 쓰세요.
- 브라우저의 방문 기록·사이트 데이터를 지우면 입력값도 지워져요.

[필요한 것]
- Windows 10 또는 11, 인터넷 연결(처음 받을 때와 새 버전을 받을 때).
