# 바뀐 내용

## 종이 배경·카드·입력칸 디자인
- 배경의 종이색과 밝은 카드의 차이를 키우고, 옅은 금색 빛과 블러시 그라데이션을 더했어요. 다크 모드는 남색 배경 위에 카드와 입력칸이 구분되게 밝기를 맞췄어요.
- 예산·진행 순서·하객·알아둘 것·신혼여행·둘이 정할 것의 카드, 펼침 제목, 버튼 모서리와 그림자를 통일했어요. 신혼여행 목적지는 각각 종이 카드로 묶었어요.
- 입력칸은 48px 이상으로, 입력 중인 칸은 청색 테두리와 옅은 바탕으로 보여 줘요. 직접 입력과 자동 계산값, 참고 시세는 서로 다른 면으로 구분해요.
- D-day 띠에서 이름·D-day 아래에 날짜 전체 폭을 주고, 날짜·준비 현황·펼친 묶음의 보조 제목을 14px로 맞췄어요.
- 앱은 CSS만 바꿨어요. 문구·사실·계산·저장·이벤트·ID·data 속성은 그대로예요. 외부 이미지나 새 라이브러리·애니메이션은 없어요.
- `docs/screenshots/README.md`에 390px 라이트·다크 11개 화면의 전후 44장을 추가했어요. 이전 화면 기록도 보존해요.

## 첫 화면 줄이기
- 결혼식 날짜를 정한 뒤에는 첫 화면의 청첩장 카드가 얇은 띠로 접혀요. 띠에는 이름, 날짜·시간, D-day가 보이고, 그 아래에 진행 막대와 남은 일 요약이 있어요.
- 띠를 누르면 원래 청첩장 카드가 펼쳐지고, ‘청첩장 카드 접기’로 다시 접어요. 접었는지 펼쳤는지는 그 기기에 기억돼요(`wd-hero`, 공유 데이터에는 저장하지 않아요).
- 날짜를 처음 정한 방문에서는 청첩장 카드를 한 번 펼쳐서 보여 주고, 다음부터 얇은 띠로 시작해요.
- 결혼세액공제 안내는 띠 상태에서 한 줄 요약으로 보이고, 누르면 전체 안내가 펼쳐져요.
- 높이 844px 휴대폰 기준으로 탭 위치가 857px에서 303px(폭 390px), 365px(폭 320px)로 올라와서, 앱을 열면 탭과 목록이 첫 화면에 바로 보여요.

## 펼친 줄 색 구분, 여닫기 쉽게
- 진행 순서·예산·식장 견적·하객·둘이 정할 것에서 줄을 펼치면, 그 줄이 머리띠(색)와 색 있는 상자, 왼쪽 금색 줄로 묶여 어디부터 어디까지가 펼친 내용인지 바로 보여요. 입력칸은 상자 안에서 흰 바탕과 금색 테두리로 도드라져요.
- 예산 항목은 펼친 상자 안을 ‘금액과 날짜’와 ‘그 밖’으로 나눴고, 자동으로 계산되는 잔금은 파란 점선 칸으로 구분했어요.
- 열리는 줄마다 오른쪽에 화살표가 붙고(접힘 ∨, 펼침 ∧), 이름뿐 아니라 금액·날짜·화살표 쪽을 눌러도 열리고 닫혀요.
- 펼친 상자 맨 아래에 ‘닫기’ 단추가 생겼어요. 누르면 접히고 그 줄이 보이는 자리로 돌아가요.
- 접는 묶음(예산 분류, 가격 비교 묶음, 비교안 검토, 알아둘 것, 촬영 체크리스트 등)의 ‘+/−’를 네모 안의 화살표 단추로 바꾸고, 펼친 묶음의 머리에 색을 넣었어요. 예산 분류 머리는 눌리는 띠 모양이에요.
- 가격 비교 탭은 아래 ‘가격 비교: 금액 입력·접기 영역 구분’(GPT 작업, [PR #20](https://github.com/dudwlstjr3-maker/marry-me/pull/20))의 디자인을 그대로 쓰고, 여닫는 표시만 다른 탭과 같은 화살표 단추로 맞췄어요.
- 접힌 묶음을 열자마자 다른 값을 바꾸면 도로 접히던 문제를 고쳤어요(누르는 순간에 열림 상태를 먼저 적어 둬요).

## 가격 비교: 금액 입력·접기 영역 구분
- 접기 제목을 종이색 버튼 면으로 구분하고, 펼치면 금색 바탕과 구분선이 보여요. 제목 전체를 누를 수 있고 오른쪽 표시도 같은 위치에 있어요(하위 48px·상위 56px 이상). 오른쪽 표시는 위의 ‘펼친 줄 색 구분’ 작업에서 +/− 대신 화살표 단추로 맞췄어요.
- 직접 넣는 금액은 금색 배경과 두꺼운 입력 테두리로, 참고 시세는 별도의 종이색 영역으로 나눴어요. 입력 중에는 청색 포커스 테두리가 보여요.
- 가격 비교 탭 안에서만 CSS를 바꿨어요. 문구·동작·저장·가격 자료·시험 선택자는 그대로예요.
- 390px 라이트·다크의 접힌 화면, 펼친 가격표, 입력 중인 금액, 직접 추가 전후 화면 16장을 추가했어요.
