# 바뀐 내용

## v24 (Codex)
- 첫 화면을 흰 꽃과 얇은 금색 테두리의 청첩장 카드로 변경. 신랑·신부 이름, 예식 날짜·시간을 가운데 두고 D-day 숫자를 강조.
- 아이보리·연한 블러시 그라데이션과 글자 밖 여백의 옅은 레이스. 다크 모드는 깊은 남색과 따뜻한 금색으로 구성.
- 진행률만큼 채워지는 버진로드와 양옆 꽃장식. 기존 청실·홍실과 매듭은 길 끝의 리본으로 유지.
- 진행 순서·예산·하객 등 카드와 제목의 색·여백을 통일. Hahmlet 명조 제목과 읽기 쉬운 기존 고딕 본문 유지.
- 첫 화면 꽃잎 3장만 transform·opacity로 천천히 낙하. 동작 줄이기 설정에서는 끄고, 기존 너비 전환 효과 제거.
- 장식은 인라인 SVG·CSS만 사용하며 접근성 트리·클릭에서 제외. 저장 로직, 사실·문구, 고정 ID, data-fk, 탭 구조 유지.
- 390px 라이트·다크 전후 스크린샷을 첫 화면·진행 순서·예산·하객·알아둘 것까지 갱신(20장). 촬영 조건은 `docs/screenshots/README.md`에 기록.
- 장식 SVG 30KB 제한·동작 줄이기·화면 고정 검사를 추가. 시험은 320·360·390·430px × 라이트·다크에서 대비 4.5:1, 터치 44px, 가로 넘침 및 기존 기능을 확인.
- package.json과 package-lock.json 버전을 24.0.0으로 맞춤.

## v23 (Claude)
- 화면이 좌우로 밀리지 않게 고정: 화면 폭 밖으로 나가는 부분은 잘라내고(`overflow-x: clip`), 진행 순서는 손가락으로 세로로만 움직이게(`touch-action: pan-y`).
- 원인 하나 수정: 접는 상자(details) 안의 입력칸은 box-sizing이 상속되지 않아 8px씩 넘쳤음. 입력칸·버튼에 `box-sizing: border-box`를 직접 지정.
- 모든 탭에서 접는 상자를 다 연 상태로 폭 360·390px(스크롤바 표시)에서 넘침 0 확인. 80개 시험 통과.

## v22 (Claude)
- '항목별 가격 비교표' 카드 하나로 정리: 읽는 법 → 전체 비용 → 예식장 → 스튜디오 → 드레스 → 메이크업 → 스드메 묶음 → 시기·계약 시점 → 업체별 가격 확인. 줄마다 기준(중간값·평균)과 조사 시점 표시.
- 흩어져 있던 '결혼식장 비용', '지역별 결혼 비용', '스드메·추가금 가격표' 카드를 위 카드로 합침. '견적서 밖에서 나오는 돈'에서는 숫자를 빼고 질문 목록만 남김.
- 최신 값 반영(2026년 2월): 스튜디오 137만원, 드레스 160만원, 메이크업 79만원, 생화 280만원, 결혼식장 1,550만원. 예식장 추가금(사회자·도우미·폐백·원판) 추가.
- 예산의 예식·스드메 묶음에서 가격표의 해당 항목으로 바로 이동.
- 가격표는 휴대폰에서 '항목·금액 / 기준·시점' 두 줄로 표시.
- 시험: 가격표 시험을 새 구조로 교체. 80개 통과(`ALLOW_CONTENT_CHANGE=1`).
