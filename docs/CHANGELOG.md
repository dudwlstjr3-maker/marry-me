# 바뀐 내용

## 견적서를 PDF·여러 사진 형식·글로도 넣기
- ‘견적서 사진·PDF로 넣기’에서 PDF, 아이폰 HEIC 같은 다른 사진 형식, 글 파일(.txt)을 함께 고를 수 있어요. PDF는 쪽마다 그림으로 바꾸고(pdf.js, PDF를 고를 때만 불러와요), Claude가 바로 받지 않는 사진은 JPG로 바꿔 보내요.
- 문자·카톡으로 받은 견적은 ‘붙여 넣기’에 넣고 ‘글에서 읽기’를 누르면 돼요.
- 한 번에 보낼 수 있는 그림 수를 넘거나 읽을 수 없는 파일이 있으면 확인 상자에 알려 주고, 비밀번호 PDF·한글 문서처럼 못 여는 파일은 캡처해서 넣으라고 안내해요.

## 읽기 쉽게 정리 (탭 한 줄, 빈 예산 분류 접기, 보조 글자 키우기)
- 탭 7개를 두 줄로 쪼개지 않고 한 줄 15px로 보여 줘요. 화면보다 길면 옆으로 밀어 보고, 고른 탭은 저절로 보이는 자리로 와요. 오른쪽 끝의 흐림이 더 있다는 표시예요. 탭 순서와 이름은 그대로예요.
- 예산 탭의 분류(예식·스드메·예물·예단 …)를 접는 상자로 바꿨어요. 금액을 넣은 분류만 펼쳐 두고, 비어 있는 분류는 ‘입력 전 · 3개 중 0개 입력’ 한 줄로 접혀요. 누르면 열려요.
- ‘비교안으로 예산 검토’는 처음에 접혀 있고, 제목 줄에 ‘서울 예식안 · 반영 9/9개 · 169만원 초과’처럼 결론을 보여 줘요.
- 예산 탭 길이가 390px 기준 7,327px에서 4,710px로 줄었어요.
- 설명·출처 같은 보조 글자를 13px에서 14px로 키우고, 회색을 더 진하게 했어요(라이트 대비 약 5.9 → 6.9:1).

## 예산 한눈에·견적서 사진 읽기·지역 평균 한 줄 비교
- 예산 탭 맨 위에 ‘우리 예산 한눈에’ 카드: 총예산 입력과 예상 총액·남은 돈·앞으로 낼 돈·축의금 빼면 실제 부담 네 숫자만 먼저 보여요. 항목별 예산 합계·낸 돈·누가 내나·받은 축의금은 ‘자세히 보기’에 접어 뒀어요. 계산은 그대로예요.
- 식장 견적마다 지역 평균(대관료·1인 식대)과의 차이를 ‘서울 강남 평균보다 약 50만원 비싸요’처럼 금액 하나로 먼저 말하고, 아래에 대관료·식대 차이를 풀어 써요. 식대 차이는 보증인원을 곱해 만원으로 보여 줘요. 예전의 잘리던 한 줄(‘1인 식대 0.2만원 낮음’)을 대신해요.
- 견적서 사진으로 넣기(claude.ai 앱에서만): 견적서·계약서 사진을 고르면 Claude가 홀 이름·예식 일시·보증인원·1인 식대·대관료·필수 추가금을 읽어요. 저장 전에 확인·수정할 수 있고, 흐리거나 단위를 고쳐 읽은 칸은 ‘확인 필요’로 표시해요. 사진은 저장하지 않고, 읽은 추가 비용 내역과 알아둘 점은 견적 메모에 들어가요. 저장 형식은 기존 견적(`budget.quotes`)과 같아요. GitHub Pages·내려받은 파일에서는 버튼이 보이지 않아요.
- 직접 넣은 금액과 예산이 같을 때 ‘시세와 같아요’ 대신 ‘비교안과 같아요’, ‘예산이 이미 비교안 금액과 같아요’로 말해요.
- 320px에서 예산 검토 차액 배지(‘169만원 초과’)가 두 줄로 갈라지지 않아요.

## 가격 비교·예산 화면 정리 (Codex)
- 비교안 선택·이름·합계는 핵심 카드에 모으고, 설명과 새 비교안 추가·접기 도구는 아래로 구분했어요. 기존 정보는 숨기지 않았어요.
- 직접 추가·담긴 항목·나란히 보기·지운 항목의 접기 모양을 통일했어요. 담기는 체크와 금색 선으로 표시하고, 직접 금액 입력을 참고 시세보다 강조해요.
- 예산 검토의 긴 항목명에 한 줄 폭을 주고, 비교안 금액과 내 예산은 같은 오른쪽 기준선에 맞췄어요. 초과·여유·일치·미입력 상태와 참고 배지의 모양을 정리했어요.
- 320px 입력칸을 넓히고 탭과 수정 대상의 보조 글자를 13px 이상으로 맞췄어요. 탭 이름과 순서는 유지하며, 긴 이름은 같은 줄의 탭 버튼 안에서 두 줄로 표시해요.
- 백업 칸, 식장 견적의 바꾸기 확인, 축의금을 뺀 실제 부담도 종이색·금색 선·명조 제목에 맞췄어요.
- 화면 문구·기능·저장 구조·이벤트 표식·가격 데이터는 그대로예요. 390px 라이트·다크 전후 화면은 `docs/screenshots/README.md`에 모았어요.

## 가격 비교 ↔ 예산 연결 (Claude, PR #4 위에 작업)
- 가격 비교: 표의 행이 아니라 항목 28개를 하나씩 담고 뺄 수 있어요. 담은 항목에는 받은 견적이나 예상 금액을 직접 넣어요(식대는 1인 금액). 참고 시세가 여럿이면(이전 조사, 지역별 값, 성수기/비수기 등) 고르는 칸 없이 모두 펼쳐 보여 주고, 금액을 비우면 지금 지역에 맞는 ‘기준’ 값으로 계산해요.
- 그 밖에 드는 비용: 가격표에 없는 비용 52개를 9묶음(꽃·부케, 도와준 사람 사례, 예식 당일·식장, 의상·꾸밈, 예물·예단·함, 청첩장·하객, 상견례·양가·준비, 신혼여행, 신혼집·혼수)으로 넣었어요. 항목마다 알아둘 점과 연결되는 예산 항목을 적었고, 참고 시세 없이 금액을 직접 넣어요. 금액을 비운 항목은 합계에서 빠졌다고 알려 줘요.
- 목록에도 없는 비용은 비교안마다 이름·금액·예산 항목을 정해 직접 추가해요.
- Windows 실행 폴더 `launcher/`: `start.bat`이 GitHub에서 최종본을 받아 열어요. 받지 못하면 전에 받은 파일을 열고, 직전 버전과 받은 시각을 남겨요.
- 가격·예산 체크 버튼의 체크 표시를 CSS로 그려 인라인 SVG를 줄였어요(18.8KB → 13.7KB).
- 비교안: 이름 있는 비교안을 여러 개 만들고 바꾸고 지울 수 있어요(지우기는 한 번 더 확인). 비교안별 합계와 ‘비교안 나란히 보기’(합계·분야별)를 보여 줘요. 값이 쌍으로만 있는 항목은 범위로 합산하고, 식대는 1인 시세 × 예산 탭 보증인원(없으면 최소 보증인원 중간값 200명)으로 계산해요.
- 지역은 가격 비교와 예산에서 같은 값을 써요. 비교안은 고른 시세를 그대로 두고, 지역과 다른 값이 있으면 알려 주고 ‘○○ 시세로 맞추기’를 눌러야 바뀌어요. 묶음 가격(계약금·패키지·전체 비용)과 그 안의 항목을 함께 담으면 겹칠 수 있다고 알려 줘요.
- 예산 탭 ‘비교안으로 예산 검토’: 비교안을 고르고 항목별로 반영 여부를 정하면, 예산 항목(b01~b27)별로 비교안 금액(직접 넣은 금액, 없으면 참고 시세)과 참고 시세, 내 예산, 차액(초과/여유), 합계를 보여 줘요. 내 예산은 이 자리에서 바로 입력해요.
- 기존 예산·확정·낸 돈은 바꾸지 않아요. 비교안 금액은 항목마다 ‘넣기’나 ‘바꾸기 (지금 ○○)’를 눌러야 예산 칸에 들어가요.
- PR #4의 행 단위 저장(`items[행 ID]`)과 그 전의 `pricePlan[행 ID].include`·`amount`(내 금액)도 새 항목과 기본안의 직접 금액으로 읽어요. 가격표 문구와 숫자는 그대로이고, 표의 행 데이터만 `PRICE_TABLES`로 옮겼어요.
